# FieldAuth – NHAI Hackathon Project

## Overview

FieldAuth is a mobile application designed to authenticate and manage field personnel operations efficiently. The system provides secure user verification, monitoring, and workflow management for field staff.

## Features

* Secure User Authentication
* Mobile-Friendly Interface
* Real-Time Data Management
* Role-Based Access Control
* Field Activity Tracking

## Technology Stack

* React Native
* TypeScript
* Node.js
* Android Studio

## Project Structure

src/
├── screens/
├── components/
├── services/
├── navigation/
├── assets/

## Installation

1. Clone the repository

git clone https://github.com/RajeshkhannaBhuthkuri/FieldAuth_hackathon_project_NHAI.git

2. Install dependencies

npm install

3. Run the application

npm start
